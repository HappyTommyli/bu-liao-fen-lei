# 人工机械标定及固定采集起点
用户选定人工标定并授权修改脚本。沿用现有ZERO ALL指令，无固件改动/实物操作。人工对准命名固定基准后确认将当前位置作为机械(0,0)，与仅供手动相对对位的临时坐标区分。标定只在本次连接内有效，需等待ZERO确认及零坐标状态；重连、运动中止导致参考失效、脉冲换算改变、单轴重设零均失效。对位阶段只允许手动相对/点动；自动函数和绝对定位要求机械标定有效。旧API ZERO ALL等价人工原点确认以保持兼容，主界面改人工标定入口。
独立保存采集起点X/Z及指定安全Z（Z负向为上）。手动返回和动作表新capture_start动作采用先Z抬升到min(当前Z,指定安全Z)，再X，最后Z；安全Z须<=起点Z。逐段验证边界与运动时间，禁止没有起点或未标定时调用。不自动返回或设零；批量重复按用户动作表执行。保存起点绑定脉冲换算；变更换算后需重存。新启动保留起点、基准名，坐标有效性不恢复。新基准名需要重新保存起点。
原23列CSV不变，元数据记录人工机械参考与采集起点、标定ID。自动保存兼容旧设置及函数。验证只用模拟设备/临时文件。
