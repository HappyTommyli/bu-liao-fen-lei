# 批量采集、设置恢复与记录回收设计（用户已批准）

## 意图与方案
沿用 Linux PySide6 工作台，当前动作函数重复 N 次；相比多函数队列，不增加新任务编辑器。每轮成功保存后等待间隔再继续，异常停止整批。整批路径从上一轮终点继续，启动前检查所有轮次，不自动设零/回起点。每轮独立编号，重启/基线分段保持现有行为；批次ID和轮次放元数据，23列CSV不变。

配置修改后自动原子保存；恢复目录、布料、运动参数、固定距离/模式、动作草稿和批量参数，保留函数导入导出。目录不可用时明确报错且不换目录；方向键默认关闭，不恢复使能、有效坐标、基线或运行任务；边界数值恢复但需确认启用。

记录支持多选移入当前目录隐藏回收站，确认列名称/数量，阻止当前采集和后台保存数据。最小空闲正序号分配，删除/重命名释放旧名称；恢复若冲突则重新编号。仅操作当前根目录的真实记录文件夹，拒绝符号链接和越界路径。继续使用目录锁。

## 约束与实现选择
不连接或移动实体电机；测试用模拟设备和临时目录，不改用户数据及固件。复用 Worker 单线程所有权和 Recorder 异步收尾，批量在 Worker 内调度。设置持久化与 Catalog 使用共享加锁合并写入，避免 last_label 丢失。界面不增加独立批量页面。

## 验收
三轮生成独立记录且位移符合三次执行；保存失败/中止/轮末停止阻止未来轮；关闭重开恢复参数和未导出草稿；删除后编号可复用，恢复保留CSV字节；禁止操作在写记录，原CSV列不变。
