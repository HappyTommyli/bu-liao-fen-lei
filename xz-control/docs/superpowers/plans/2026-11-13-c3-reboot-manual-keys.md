# C3 采集固件重启与方向键作用域

用户提供 `/home/serein/classify-cloth/mlx_c3_monitor.ino` 并要求按源码板型处理；目标明确为 XIAO ESP32-C3，源代码完全没有 Serial.read/available，状态输出与实机截图一致。此证据替代此前口述的 ESP32-S3；目标板型是源码配置，不等于芯片实物读取结果。

用户追加：恢复启用方向键开关，仅手动控制窗口生效。实现为默认关闭、手动 tab0、主窗口前台同时满足才驱动；切页、关闭开关、切窗停止当前点动；其他页面与设置窗口保留方向键编辑导航。鼠标点动独立。
