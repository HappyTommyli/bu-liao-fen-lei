# CERA 布料分类训练工作台

启动：`bash 启动布料分类训练.sh`。当前桌面默认单通道 **|dBy| 累积前缀 CERA**，只保留“数据集、模型训练、实验结果、在线识别”四页；独立新数据识别已合并到在线识别的新数据回放。

## 当前操作流程（2026-11-23）

1. 启动自动读取相邻 `xz-control/data/布料采集数据新`。默认去程51～140mm、回程120→30mm，仅检查By自身质量；原始CSV只读。训练前仍按原CSV/采集组划分，标准化只拟合训练部分，固定20%测试集不参与训练及在线门槛调试。
2. 在“模型训练”调整TCN通道/块数/卷积核/膨胀、GRU隐藏维数/层数、Dropout、优化器及训练轮数。“最少观察量”默认900点，“前缀增长间隔”默认900点。每个前缀都从有效范围起点开始，不丢弃历史；训练时每单程每轮随机选最多2个前缀、单程总权重为1，验证/测试以最终前缀评价。默认只训练一次；验证次数可选1或2～10折。GPU不可用时明确提示，不自动换CPU。
3. 训练后在“在线识别”选择该模型：验证集调试／新数据回放／实时采集→开始。“高级设置”收起概率、前两类概率差、连续确认次数（默认2）、稳定秒数、预测间隔等参数。模型每次读取全部已收到的有效历史；同一类别同时满足全部门槛后输出并锁定，此后不再推理或改判，采集继续正常进行。置信概率不等于实际正确率；始终未达标会显示未确认。
4. “当前过程”显示已收到的|dBy|、前三类概率、锁定竖线和时间光标；锁定后的信号变灰，不生成新的概率。卡片显示锁定类别、有效用时和位置。“批量结果”每页100条，点击记录可回看缓存的过程；超过缓存限额可单独回放原CSV。相对有效范围末尾的提前量仅在该单程结束后计算，各类表现和混淆矩阵在结果内查看。
5. “更多”提供暂停、清空与JSON/CSV导出；导出包含时间线。正式测试入口折叠，冻结门槛和模型哈希后才可评价固定测试集，首次正式测试策略的持久绑定继续有效。新数据若反复用于调参，应视为调参数据。

真机连接顺序：采集端开启“允许实时转发→开始转发”，训练端选“实时采集→开始”，然后在采集端运行原布料扫描流程的“运行并采集”。仅手动“开始采集”时为 `manual_idle`，尚未进入 `step_003/step_004`，应显示等待扫描；不能把手动移动自动当作训练定义的去回程。

累积前缀权重使用独立版本 `configurable-cera-prefix-v1`，需要新建实验重新训练。历史窗口模型与冻结策略仍可读取，并明确标注其窗口方式，不会自动变成累积模型。历史对照配置仅保留兼容，不再作为新实验默认入口。

模型列表/实验详情解析与在线推理在独立进程运行；数据版本保存载入、策略校验和结果导出在后台执行，显示等待阶段、耗时及取消入口。过期异步结果不覆盖当前选择；回放完成后仍分批刷新，隐藏图表按打开时绘制。耗时任务期间可继续浏览页面。实物采集转发仍需在采集脚本内主动开启，本次修改不启动采集或真实数据训练。

验证：`QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q`。截图：`.venv/bin/python train_cloth.py --screenshot training.png --page 1`。实现方案见 `docs/superpowers/specs/2026-11-23-prefix-stop-responsive.md`。

# 布料分类训练脚本 · R3

启动命令保持不变：`bash 启动布料分类训练.sh`。已有独立`.venv`；换机器先运行`bash 安装依赖.sh`，Python≥3.10。离线使用，不操作电机。Linux保留Wayland检测和Qt启动修复。

## 工作流程

1. **数据集**：导入CSV或文件夹即执行完整性、单次幅值和固定批次类别审查。显示扫描、可训练、建议复核、排除、无法判断和数据错误数量；所有记录保留显示，只有具训练资格的可勾选。点击记录看指标和原因，可导出完整审查报告。错误/无法判断项不准入，其他合格记录仍可训练。
2. **输入与训练**：默认`|ΔBy|`；可单选双通道`[|ΔBx|, |ΔBy|]`，或同时比较。独立GRU/TCN/CERA，完整单程一次分类交叉熵，无风险头、前缀损失或采集提前停止。每CSV两条单程保持同组。
3. **数据版本**：“保存数据集版本/载入数据集版本”冻结准入片段、标签、完整审查批次、排除清单、CSV/元数据指纹、协议和五折。新增文件不会混入已启动任务。快照可移动，载入时校验，不重复裁剪或减基线。快照同时冻结所需通道和有效点规则；更改单/双通道筛查范围需重新导入原始CSV建立新版本。快照不含原始CSV备份。
4. **模型库**：每种模型配置一行，折和随机种子收在详情里。训练完成先看验证结果；选定预先计划的配置后运行折外测试，自动包含该配置全部折和种子，并锁定候选。可以查看当前具体折，或同种子的合并折外混淆矩阵。
5. **模型识别**：选择具体折/种子权重，添加CSV。逐单程展示类别；“识别混淆矩阵”仅统计有已确认真实标签的结果，默认只计新数据。可切换去程、回程、回放或全部；无标签、标签集外记录显示数量并排除，空样本准确率显示不适用。

**识别混淆矩阵**行是真实类别、列是预测类别。导出当前矩阵会保存PNG、CSV、JSON，记录模型、筛选范围及统计。不同模型的预测不会混在同一矩阵中。回放包含该实验已使用过的来源/采集组，不算新数据泛化成绩。

**正式训练仍按用户安排暂停。** 代码交付与流程测试不等于启动全量正式实验。第二阶段风险与提前停止仍显示后续开放。

## 处理规则

- 新默认固定位置窗：step_003去程51–140mm，step_004回程120→30mm。旧项目保留其保存的范围；不按Bz突变或By包络自动裁剪。
- 新协议`abs-v3`两方向逐通道取绝对值，回程不反转。默认333Hz，过去最近有效值保持，最大缺口20ms；名义范围/速度扣200ms尾部余量。边界覆盖容差2mm随协议保存。
- 标准化仅用每折训练部分的逐通道全局均值和标准差。既不对全数据拟合，也不逐单程消去幅值差异。
- By仅要求相关磁信号；Bx单通道仅要求Bx，双通道/模长要求XY。未使用的Bz不作为新排除条件；采集器已有无效标记保留。
- 同时比较单、双通道时，分别缓存各自的有效采样与处理结果；By模型不会因为未使用的Bx缺值而改变输入。数据快照保留这些独立片段，识别继续使用模型对应的处理规则。
- 检查悬空基线和差分来源。核对`dBy=By−By0`，默认舍入容差0.01µT；记录有效接触样本实际核验数。用于输入的delta若缺少可验证原值，标记无法判断；只有原值时由明确基线直接计算。缺基线、冲突、时间/缺口/协议或完整片段问题显示具体原因，不用0或曲线均值伪造基线。
- 高原始采样率时使用固定声明时基上的因果保持及抗混叠FIR，并记录延迟；不压缩无效点所占的时间，不使用未来插值。
- 递归导入跳过`.workbench-trash`、`outputs`、`.venv`、`.git`、`__pycache__`。内容去重；同内容标签/元数据冲突列为待处理，跨批导入也检查。

## 数据审查与训练准入 · admission-v1

历史7次（亮丝欧根纱001/002/003、亮丝粗花呢002、仿皮毛一体001、平纹棉布001、覆膜帆布001）同时匹配CSV和metadata指纹时，标记“本实验排除·建议复采”，两方向一起不准入。历史11次边界记录标记“可用·建议复核”，不会仅因旧标记排除。同名新采集重新审查；旧整类20条建议不直接决定新实验资格。原数据及旧资源不改写。

| 审查标记 | 本次训练 |
| --- | --- |
| 可用·审查通过 | 是 |
| 可用·建议复核 | 是，正常权重 |
| 本实验排除·建议复采 | 否 |
| 待复核·无法判断 | 暂不参与 |
| 不可用·数据错误 | 否 |

使用未标准化的有效`|ΔBy|`。完整窗和共同X区间的中心值各自直接取有效采样中位数，差异率为`|回−去|/((回+去)/2)`；位置箱仅检查持续同向。完整/共同差异率均≥10%、偏差同向、共同幅值差≥max(5µT,3×基线噪声标准差)、共同位置箱同向比例≥80%，四项同时满足才新判排除。任一差异率≥10%但条件不全为复核；缺噪声、共同箱不足或分母≤1e-6µT为无法判断，不能算通过。

分箱参数明确保存：2mm、每方向每箱至少3点、至少10个共同有效箱。报告包含阈值、观测值、指纹、触发条件、资格和规则版本。无效采样仍沿用既有因果保持及缺口限制；仅凭软件位置和磁采样不能证明撞击、离面没有发生。审查不使用模型错分或同类平均值离群规则。

每次导入固定一个批次；增量新候选另建批次，已有文件重导仍刷新其完整原批次。以独立采集组计数，去回不重复；组内全部可评估才入分母，全部大幅异常才入分子，混合结论保守保留。至少10个可评估组且异常率≥80%才“本批次该类暂不启用”；不足10组仅提示复核。报告显示分子、分母、无法判断数。取消勾选、移除显示行不重算批次比例；更改标签、通道、协议及恢复项目时，完整原批次分别重审，不合并原增量批次。

训练前校验完整批次及当前准入版本，仅合格且选中的记录进入五折。新快照保存全部审查结论（包括排除记录），只保存准入选择的训练片段。CLI与GUI使用同一准入检查。旧快照不重新解释或覆盖，可只读查看；开始新训练或继续旧未完成任务须从原CSV按当前规则重新审查。旧完成模型继续按原协议识别、评价。

## 五折与参数

按采集组建立A–E五折，每轮测试一折、验证下一折、训练其余三折：A/B/CDE，B/C/ADE，C/D/ABE，D/E/ABC，E/A/BCD。每组恰好一次折外测试。同CSV、同capture_session及未来前缀不可跨区。

检查实际类别覆盖和组结构，不再以每类10组作为唯一门槛。少于5个独立组无法覆盖五折；达到5组仍需检查会话约束。所有对照使用同一冻结快照及五折。

默认3主干×1输入×5折=**15项**，两输入为**30项**。高级设置可选重复种子、Bx、XY模长和最后时刻读出对照；任务数随选择显示。五折是评价流程，不是一份可加载权重。

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 正式预算 | 200轮/折 | 默认不因停滞提前结束，仍保存验证最佳权重 |
| 学习步幅 | 0.001 | AdamW；可用0.0003作事先确定的对照 |
| 每批单程 | 16 | 内存不足先减到8，不缩短序列 |
| 权重衰减 / dropout | 0.0001 / 0.1 | 减少过度记忆，不是越大越好 |
| 模型宽度 | 64 | GRU单层单向；TCN32/64/64；CERA门控及证据递推 |
| 梯度裁剪 | 1 | 控制梯度范数 |
| 学习率调度 | 开启 | 验证损失停滞8轮减半，最低0.00001 |
| 训练停滞提前结束 | 关闭 | 高级选项；开启后默认耐心30轮，与采集提前停止不同 |
| 划分/训练编号 | 42 / 42 | 分别保存；重复种子改变初始化，保持五折固定 |
| CPU线程 | 2 | 影响速度，不是准确率开关 |

最佳轮次按验证Macro-F1，同分比较验证CE。测试不选轮次、超参或阈值。快速检查是试跑，不用于正式识别/测试；修改其参数不会把它自动升级为正式成果。

## 成果、继续任务与兼容

新格式`cloth-classification-v3`，默认`outputs/models/`。保存数据快照、每组分折、每折scaler与权重、处理版本、参数、筛查、历史、预测、报告和汇总。逐折均值/标准差与合并折外成绩分别报告，并提供逐类、方向、质量提示、主要混淆、训练验证差距及耗时。

“继续未完成任务”沿用冻结快照与配置，跳过已完成且校验通过的折；未完成折恢复最近完整轮，最多重跑未保存的一轮，历史曲线同时恢复。旧任务没有恢复点时明确提示该折从第1轮重跑，旧历史保留为`history-before-restart.json`。恢复点损坏或配置/数据/环境不一致时拒绝继续，不静默重跑。不同输入或新增数据要建新版本。成果包包括快照和各折权重；无需源CSV仍能查看和复跑冻结评价，但原始CSV应另行保留。

旧`cera-net-v1`和`cloth-classification-v2`放在旧版记录中，只读查看和识别，使用旧预处理规则。新版两方向绝对值不会改变旧模型输入。历史实验成绩不冒充新版全量结果。

识别须选择具体权重。若另外用全数据重训部署模型，需新建版本；原折外数据已参与重训，不能作为新权重独立测试。阶段二以后必须绑定明确父权重。

## 数值保护与按轮恢复 · numerical-safety-v2

模型和输入保持32位精度，梯度范数及裁剪乘法使用64位计算，随后写回原梯度类型，统一裁剪上限为1。有限但很大的梯度正常裁剪；真正包含NaN/Inf的梯度、裁剪后异常或更新后异常仍中止，不跳过批次、不自动改变学习率。每批次同时检查输入、输出、损失、参数和AdamW状态。验证出现非有限值也中止。默认学习率仍为0.001，想比较0.0003请建立独立实验，不能在同一五折任务中混用。

每折保存一个`recovery.ckpt`，包括当前轮参数、优化器、调度器、随机状态、最佳权重、标准化参数与历史。初始化保存第0轮，之后在完整训练、验证和学习率调度完成后原子保存，并校验内容与冻结任务关联。它与正式导出的验证最佳权重`model.pt`分开。任务记录中的“继续未完成任务”沿用原冻结配置，跳过已完成折，恢复未完成折。预算或早停已完成时直接保存最佳模型。

数值失败时，任务日志显示本次独立诊断文件`numerical_failures/<记录编号>.json`的位置，以及可恢复的轮次。每次报告分别保留，重复失败不会覆盖；`numerical_failure.json`另存最新报告，方便查看。报告记录异常阶段、轮次/批次、CSV/方向、输入范围、梯度/参数摘要和规则版本。更新后发现异常的内存参数不会覆盖最后有效恢复点。重复出现同样异常时，恢复原配置可能再次失败；根据报告定位，参数试验另建任务。

每轮保存裁剪前最大范数、最大单项梯度、裁剪批次比例、裁剪后最大范数和最小裁剪系数。比例表示本轮有多少批次的原范数超过1，不是分类准确率。裁剪前范数超过32位安全计算范围时，界面只显示“大梯度已安全裁剪”，细节在记录中。

旧数值版本的未完成任务：点击“继续未完成任务”会自动建立`CLOTHFIX`修复验证副本，只验证当前未完成折，原任务保持不变。v1恢复点只有在副本中、其余冻结配置/数据/模型/折/种子/环境完全匹配时才允许兼容，副本保存来源、恢复点SHA256和原始恢复点备份；当前v2任务继续时不会再复制。没有恢复点的旧任务只能从该折第1轮开始。副本在任务记录中标记“修复验证（非正式）”，不能用于正式识别或折外测试；正式比较应新建v2实验，让所有折统一从头训练。

本次修复执行自动测试和真实失败两批的内存重放，不启动正式训练或200轮长段验证，也不改写已有失败实验。两批通过不代表完整训练必然稳定；完整预算验证应在后续独立副本中执行。

### 新实验：GPU 标准流程（v4）

界面只使用 NVIDIA GPU / FP32，不提供GPU/CPU选择框；训练启动时自动检测环境，GPU不可用会明确停止。CPU仅保留给内部验证和命令行诊断。主实验仍为 `|ΔBy|`，去回程作为两个单程、同CSV/会话始终同组，审查规则和原始数据保持原样。

1. 导入并审查CSV；每类至少6个独立采集组，实际建议继续增加样本。
2. 固定约20%为内部测试，剩余开发集做五折比较，默认GRU、TCN、CERA，完整段交叉熵、整段均值读出。Conv-GRU、Conv-CERA为显式压缩研究对照。
3. 在模型库根据开发集验证F1选择一项配置，点击“训练最终模型”。该模型使用全部开发集，轮数取所选配置各折最佳轮数中位数，不查看测试数据。配置自此锁定。

5. 模型识别仅加载这一份最终权重。开发集折权重保存在实验内供研究，旧模型保持原有加载方式。

默认AdamW、学习率0.0003、权重衰减0.0001、有效批16、宽度64、dropout0.1。验证损失连续8轮未改善时减半学习率，连续30轮无改善结束，最多200轮；验证Macro-F1选最佳权重（相同时比较损失）。最终重训按预定轮数结束。实际微批默认经最长序列显存预检确定，显存不足可显式减小微批，有效批保持16。AMP是实验选项，默认关闭。

泛化指标默认只统计有已知真实标签的新数据。与原实验来源（包含开发集和固定留出集）文件哈希或采集组重复的记录会标记并排除；无标签和类别集外标签单独计数。数据重复检查不能证明数据从未被人工用于调参。最高概率是模型得分；多个相关窗口不作为新增独立采集样本。若根据这批结果继续调参，该批数据之后应视为开发数据，最终泛化评价需要另采新数据。

### 重叠切窗与在线验证（2026-11-21）

普通TCN工作台默认只训练一个配置一次：128通道×6块、mean+std、900点窗口。验证方式1代表单次分组划分（约60%训练/20%验证/20%测试），2–10代表固定20%测试、80%开发集K折。独立组较少时比例受整数约束；不足以覆盖每类会明确阻止训练。旧模型、旧项目缺少新字段时沿用原五折，不悄悄改变历史配置。

输入窗口新增训练步长：0为不重叠，900点窗口+450步长为50%重叠。保留首个覆盖结尾的尾窗；每条单程所有窗口损失权重归一化为1，父批仍只更新一次。训练步长与在线预测步长分别保存。更改冻结数据集的折数需从原CSV建立新版本。

第五页“在线验证”可选择已完成验证折的最佳权重或最终模型，无需额外最终重训才能调试。在线窗口长度锁定为模型训练窗口，可选预测步长为整窗、半窗、四分之一窗；概率门槛、前两类概率差、稳定秒数及可选平滑控制提前确认。默认仅评去程，可单独勾选回程。真实标签只用于评价，未知类别不会因高置信而自动得到可靠检测。运行时参数锁定，修改前需先停止。

建议先“载入冻结验证子集（调门槛）→开始回放”。CSV逐帧回放与本机实时TCP共用因果处理：固定基线/标准化，当前完整窗口，By孤立尖峰需等下一帧验证后才输出、记录该延迟；缺口、电机故障等重置窗口及稳定状态。可暂停、取消、按实时或快速速度回放。逐窗结果、每单程首次确认位置/时间、首次确认正确/错误/未确认、最终结果、反转次数、质量重置、推理耗时可导出JSON或CSV及配套汇总JSON。

验证集源CSV与metadata需匹配冻结哈希；留出数据（包括内容相同的改名副本）不允许进入阈值调试。门槛固定后导出/冻结与模型权重哈希绑定的策略，再显式评价固定留出集。首次正式留出策略会持久绑定，改变门槛后不能继续冒充同一次独立留出评价。独立新采集数据若被反复用于调门槛，应视为调参数据，不再称最终独立验证。

采集程序 `../xz-control` 已增加默认关闭的实时转发（127.0.0.1:8766）。关闭旧采集程序并人工重启后，在采集界面勾选“允许实时转发（仅本机）”并开始转发，再在训练工作台点击“连接采集程序”。传输仅包含数据，不接收运动指令。可填写本次连接的真实布料标签（仅评价），改变布料时停止并重连以更换标签。原采集设置和CSV输出保持原样，不自动重启、不自动运动。首次实物串联仍需人工验证；本次自动验证只使用模拟数据与本机socket。


### CERA与简化在线验证（2026-11-23）
