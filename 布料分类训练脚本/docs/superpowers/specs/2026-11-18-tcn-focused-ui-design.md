## 现状证据

使用现有PyQt5界面，离屏运行于1366×768、QT_SCALE_FACTOR=1和1.5：训练页实际高度621，minimumSizeHint高度828。`build_training()`把多个说明卡片、模型/通道选项、操作按钮、进度、最小高度170的图表及日志直接堆在一个无滚动的垂直布局中。该状态下标题实际高度15、文字所需23；按钮和勾选项也出现裁切。

将窗口增大到1420×1200后，同页压缩标签消失。证据支持主要原因是纵向内容超出可用空间且没有滚动/可折叠布局，不是仅由字体过小造成。100%和150%的逻辑尺寸诊断一致；不能据此声称已验证原生Wayland或所有显示缩放。

诊断截图在 `outputs/analysis/20261118_tcn_ui_audit/`，其中 `training_scale1.png` 为当前拥挤状态，`training_tall.png` 为加高窗口后的对照。现有settings弹窗已有滚动区，可复用其方式，但应减少每项参数下持续显示长段帮助文字。

## 方案选择

3. 在现有程序中增加TCN专用工作区，复用数据和训练后端；训练页重新布局、参数分组、旧功能仅隐藏。推荐采用。

- 参数区用QScrollArea，禁止控件被压低到文字高度以下；常用参数一行一项，帮助文本放tooltip或点击“说明”。不能依赖用户把窗口最大化才看全。
- 宽内容区使用左右QSplitter；内容宽度不足1000逻辑像素时切换上下布局，参数/监控均可滚动或调节比例，不能产生页面级按钮遮挡。
- 开始/取消和总进度固定在页面底部；图表、日志不争抢垂直空间，用tab切换。数据摘要最多两行，完整审查原因放可滚动详情区，不把长错误或文件路径塞进单行工具栏。
- 参数组、控件、标签根据sizeHint和字体度量计算最小高度；QSS的padding计入高度，不用固定过小高度。按钮文本不换行；长名称采用省略显示和tooltip。表格类别/路径采用可拖列、适当列宽，长审查原因放详情，不把所有列平均拉伸。
- 主窗初始尺寸按屏幕availableGeometry限制；拟支持最小1024×640逻辑像素，优先验收1280×720及以上。原1420×920默认尺寸不能无视小屏可用高度。
- 保留现有配色，字体层级以正文13–14逻辑像素、组标题15–16、页标题22–24为起点，避免全局缩小字体来掩盖布局问题。

## 两种模式

### 单配置调参

一次配置运行开发集五折；默认选900点、宽度64、六层、kernel5、dilation1/2/4/8/16/32、dropout0.1、mean读出。默认900点是本方案建议，不表示已证明优于完整单程。可切换完整单程；窗口长度仅在分窗模式生效。

允许用户改下面的结构和训练参数。任务开始前展示最终有效配置、单程/窗口数、参数量和感受野；配置随任务冻结。编辑下一次实验的参数不改运行中的任务。

### 四组对照

一次20个CV任务，四候选为完整64、完整128、900点64、900点128。固定六层、kernel5、dilation1/2/4/8/16/32、mean读出和dropout0.1。所有结构/窗口控件以四行候选预览替代，不让用户在同一批次中误改对照定义。

学习率、weight_decay、父批大小、预算和种子等训练参数在启动前可统一设置，必须四组一致。默认沿用前一份方案。四组模式生成新study revision并冻结完整定义；不能更改旧revision含义。后续要研究深度/卷积核组合，先在单配置模式进行，不把当前四组模式扩成任意网格搜索。

## 可调参数清单

| 分组 | 参数 | 默认/范围与规则 |
| --- | --- | --- |
| 输入 | 完整单程或分窗 | 单配置默认分窗；四组固定两类 |
| 输入 | 窗口长度 | 默认900；单配置整数128–8192；超过单程时保留一个真实长度窗口，不虚构8192个有效点 |
| 输入 | 窗口步长/尾段 | 首版步长自动等于窗口长度，不开放重叠；尾段保留，mask有效长度 |
| 结构 | 统一通道宽度 | 默认64；便捷选32/64/96/128/256，允许整数16–256 |
| 结构 | 残差块数量 | 默认6；范围1–10；当前每块一层膨胀卷积，避免将“6块”误写成12层卷积 |
| 结构 | 卷积核大小 | 默认5；奇数3/5/7/9/11/13/15；左右规则仍因果左填充 |
| 结构 | 膨胀系数 | 默认指数增长2^i；高级区可填正整数列表，长度须等于块数；UI显示实际展开列表 |
| 结构 | 每块通道数 | 高级区可自定义整数列表，长度须等于块数，每项16–256；关闭自定义时使用统一宽度 |
| 正则 | dropout | 默认0.1，范围[0,1)；沿用每块与分类头dropout语义 |
| 汇总 | masked mean / mean+std / max | 默认mean；std按有效时间点计算，unbiased=False，单点std=0；mean+std的分类头输入为2×末块通道 |
| 训练 | 学习率、weight_decay | 默认0.0003、0.0001；有限正学习率、非负衰减 |
| 训练 | 有效批大小 | 默认16条原始单程/更新，1–128；分窗后累积全部窗口，父单程不因窗口数量不同而加权失衡 |
| 训练 | GPU微批 | 默认自动预检；正值表示同时前向的输入段数；候选输入长度用于预检 |
| 训练 | 最大轮数、早停开关/耐心 | 默认200、开启/30；最大轮数1–1000、耐心1–1000 |
| 训练高级 | 调度器开关、等待轮数、衰减倍率、最低lr | 默认开启、8、0.5、1e-5；0<倍率<1，0<最低lr≤初始lr |
| 训练高级 | 梯度裁剪上限 | 默认1；有限正数；沿用64位稳定范数和非有限值中止规则 |
| 复现高级 | 训练种子、划分种子、重复次数 | 默认42、42、1；同批候选共享冻结分组和原单程采样顺序 |

残差连接、逐时刻LayerNorm、GELU、AdamW、FP32首版固定，不再增加一排开关。这样可调范围足够覆盖容量、感受野、切片和优化，而无需一次暴露全部实现细节。CPU线程/worker等运行参数移到折叠的运行设置，GUI默认GPU策略沿用。

自定义dilation每项建议限制为1–1024，且列表只允许十进制整数和分隔符，不执行用户输入代码；过大感受野不是非法，但页面明确显示有效输入不足导致左补零的情况。参数量和感受野预览从实际结构计算，不写死104975。

## 结构和训练语义

- 对每块一个卷积的TCN，感受野 `R=1+sum_l((kernel_size−1)*dilation_l)`。六层k5默认253点；八层默认1021点。显示点数和 `R/333` 的约时长，同时显示真实窗口时长。R超过900不能解释成看到了窗口外数据。
- 通道列表变化通过1×1残差投影匹配；卷积左填充改为 `(kernel_size−1)*dilation`，不再写死4*dilation。输出时间长度与输入一致，任意新增padding不得进入池化。
- 新增可配置TCN模块，不直接把现代CERA共用Block的行为改成新结构。新TCN按显式model_revision构建；旧bundle无revision时按旧ModernClassifier加载，旧权重键和输出保持原路径。
- 单配置和四组分窗训练都沿用前一方案：每窗与父标签计算CE，有效长度加权形成父损失；16父单程全部窗口累积后一次更新；验证/测试/识别用长度加权概率平均，不采用多数票。
- 验证主指标为父单程Macro-F1；窗口指标辅助展示。四组各自的局部输入和宽度冻结后，训练、最终重训、测试、识别全部一致。
- 有效结构、窗口、pooling、clip阈值和scheduler factor等都必须进入config/候选冻结、恢复绑定和bundle；不得只改UI值或只在训练构造中生效。

## 实施顺序

1. 先修布局并建立专用工作区：只显示TCN/By，三页导航，可滚动参数区和监控tabs。先用空数据、长审查说明、长文件名和模拟训练状态验收，不启动全量训练。
2. 增加TCN结构规范与可配置网络，确认所有参数真实影响模型、参数量或感受野；旧ModernClassifier与旧bundle加载不变。
3. 接入单配置分窗与四组实验，复用父批预算、损失、预测聚合和冻结规则；单配置默认5项，四组20项。
4. 接入结果页、最终重训、测试、模型导出/读取及恢复；所选候选实际结构必须贯穿所有阶段。
5. 小规模流程和CUDA前反向/显存预检后交付。正式20项训练由用户后续明确启动。

## 验收标准

- UI：在1280×720、1366×768、1920×1080逻辑尺寸及100%/125%/150%缩放截图核对；同时覆盖小屏1024×640的降级布局。无文字叠压、裁切按钮；所有参数可滚动到达，固定操作区始终可见。原生Wayland实测与离屏截图分别记录。
- 内容：默认只见TCN与|dBy|。导入后不能提交GRU/CERA或其他信号；模式关闭/切换、旧项目打开不会把隐藏选项带入新请求。结果页不能出现“第二阶段后续开放”等无关占位。
- 模型：宽度96、通道列表[32,64,128]、k3/k7、自定义dilation和三个pooling均能构造并前反向；参数量/感受野与实际一致；无效列表/偶数核/NaN/Inf在启动前明确报错。
- Mask与因果性：尾窗有效长度1及普通长度均正确；mean/std/max都忽略padding；给末尾添加任意padding不改变预测；改未来采样不影响更早位置的特征；std单点不产生NaN。
- 实验：四组共享分组与scaler，20个独立任务键；父批只更新一次，尾批权重正确；主指标仍按原单程统计。单配置模式参数变动不能污染四组默认定义。
- 保存与恢复：修改任一结构/窗口/聚合/优化参数会被恢复绑定拒绝；新权重导出导入及识别按保存结构重建；旧v4模型和未完成任务仍按旧规则加载/恢复。
- 测试：保留现有回归，新增TCN结构、窗口、模式/UI约束与布局测试；完整回归通过后，再进行明确记录的GPU小规模验收。不把少轮验收当作分类效果提升证明。
