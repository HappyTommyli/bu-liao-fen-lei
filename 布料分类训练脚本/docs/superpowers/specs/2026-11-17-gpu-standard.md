# GPU标准分类流程（用户已批准）

目标：以CUDA为默认训练设备，重构批量加载、优化/早停、开发集选型、最终重训和锁定测试；保留布料采集协议、审查准入、混淆矩阵和旧成果。原始CSV、metadata与真实旧任务不修改，不启动全量正式实验。

已核实机器Ubuntu22.04.5、RTX3060Mobile、nouveau驱动、无/dev/nvidia、PyTorch2.14.1+cpu；实际CUDA训练当前受系统驱动阻塞。不得把CPU测试称GPU验证，不能静默CPU回退。安装CUDA版PyTorch与检查工具，系统显示驱动安装/重启留给有管理员权限的用户，不擅改正在使用的显示驱动。

新格式cloth-classification-v4，与legacy v1/v2/v3并存。ModernConfig独立于旧TrainConfig；默认GPU、FP32、AdamW lr0.0003 wd0.0001、有效batch16、hidden64、dropout0.1、max200、验证损失调度patience8/factor0.5/min1e-5、验证损失早停patience30；最佳权重按验证MacroF1并以CE破同分。AMP为显式研究加速选项，反缩放后裁剪，真正非有限值不得无记录跳过。CPU只有显式选择才能运行。

保留By主实验、双通道/XY对照、逐方向abs、固定333Hz与有效段、正常权重及原审查批次；每CSV两条单程同组，同采集会话不拆。固定约20%独立采集组为内部测试，余80%开发集分层分组5折（每折约64%训练/16%验证）；所有配置共享分割。测试不参与标准化、选型、调参或轮数选择；旧数据上的留出只称内部测试。

GRU使用官方单向GRU与有效长度处理；TCN使用残差/膨胀卷积/逐时刻特征归一化，CERA是研究模型。整段masked mean默认、last研究对照；可明确命名Conv-GRU/Conv-CERA的因果卷积4倍特征压缩选项，原始采样不改。风险头/前缀loss继续关闭。

开发集5折比较后，按CV平均MacroF1选定一个配置，允许明确选择但不根据test。最终模型用完整开发集重训；轮数预先固定为选定配置CV最佳轮数的中位数，最终scaler只用开发集，不查看测试。最终模型与CV折权重分开登记，仅最终模型可正式识别。冻结候选和最终权重之后才能运行一次（可重复同权重）内部测试；测试后不能换候选/轮数，改进另建实验。显示单程、去回方向、按CSV往返平均概率、类指标、原始与归一化混淆矩阵；CV波动和测试分开，随机复验不算新增独立样本。

Dataset/DataLoader与固定内存异步GPU搬运，worker数可设（默认2，0合法），有效batch固定，microbatch与梯度累积支持；长短样本padding不得混入池化。缓存标准化序列避免每批重复处理。GPU预检含最大长度前反向与显存；按显存探测microbatch并冻结，运行时不静默换设备/精度。GPU数值检查聚合后再同步，异常时收集详细数据；稳定范数/裁剪保持并检查模型和AdamW。逐轮数据含梯度统计/耗时/显存。

恢复保存当前权重、优化器、调度器、早停、best、历史、Python/NumPy/CPU/CUDA RNG、DataLoader generator和AMP scaler状态，原子校验并绑定配置/数据/划分/设备/精度/环境。不同设备不冒充逐位相同恢复。正式导出best/final与recovery分开。原实验版本只读查看/识别，旧未完成任务按已有验证副本规则保留，不能混入v4。

界面保留4页，训练页显式GPU/CPU选择、设备预检和少量参数；模型库区分开发验证、最终模型、最终测试；新增训练最终模型动作，测试按钮先检查最终模型；第二阶段仍后续开放。安装脚本不再固定CPU源，诊断报告说明nouveau/驱动/PyTorch状态与管理员驱动步骤。

验收：自动测试分组/标准化隔离、训练/累积/恢复/早停、CV->final->test锁定、正式模型资格、混淆矩阵/识别、UI后台流程及所有旧功能；真CUDA测试只有cuda可用才运行并明确skip。当前不运行200轮/全量真实训练；没有可用驱动必须明确报告GPU硬件验收尚未完成。
