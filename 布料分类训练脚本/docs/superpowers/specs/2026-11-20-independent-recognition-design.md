# 独立数据识别窗口

目的：模型及参数确定后，使用新采集、未参与训练或调参的数据检查泛化表现。

## 方案

选择在现有 TCN 工作台新增第四个“独立数据识别”页面，复用现有模型加载及预测后端。独立弹窗会重复模型选择及状态管理；另建识别程序会增加预处理不一致的风险，因此不采用。

## 窗口与流程

1. 选择已完成的 TCN / |dBy| 最终模型，显示模型名称、类别、保存的输入和切片配置。不开放训练参数编辑。
2. 添加 CSV 或文件夹，独立列表显示文件及真实标签，支持移除、清空和手动指定标签。无标签也能预测；标签仅用于识别后的评价。
3. 点击开始识别。严格沿用模型保存的预处理协议、归一化、TCN 结构、切片及窗口概率汇总规则，不重新拟合或训练。
4. 展示文件、去/回程、真实类别、预测类别、最高概率及是否重复；保留类别得分和混淆矩阵。概率作为模型得分，不承诺是校准后的正确率。
5. 显示仅新数据的准确率、Macro-F1、各类表现和有效样本数量；无标签或标签集外样本单独计数，不伪造准确率。去回程可筛选，窗口不作为独立采集样本统计。
6. 导出识别明细、模型标识和评价结果，输出与训练任务分开保存，不改写交叉验证、最终模型或固定留出测试成绩。

## 隔离与检查

识别数据保存在独立状态，不写入训练数据列表或数据版本。对照所选模型来源的文件哈希及采集组标识，标记重复数据，默认排除出泛化评价。此检查只能发现已有标识所能确定的重复，无法证明数据从未被人工用于调参。

保留现有未提交修改，基于当前工作区实现。验证包含数据隔离、标签评价、模型筛选、重复排除、推理规则一致性及小屏布局，不启动真实数据训练。

## 确认

用户已回复“ok”，按以上设计实施。
